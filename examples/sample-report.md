# Illustrative report excerpt

Synthetic example for documentation, not a report from a real machine.

```text
==== cpu-info ====
Architecture:        x86_64
CPU(s):              8

==== memory-info ====
               total        used        free
Mem:            16Gi        4Gi        8Gi

==== network-info ====
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP>
    inet 192.0.2.10/24
```

The actual script writes one text file per section plus a summary and DNF reinstall helper. Missing tools and permissions affect the available information.
